# Fun-edu

Україномовний інтерактивний освітній сайт для дітей 1–4 класів. Проєкт містить навчальні вправи з математики, української мови, читання, логіки та пізнання світу.

## Перша модернізаційна фаза

- вибір класу 1–4 з адаптованою складністю;
- єдиний адаптивний інтерфейс українською мовою;
- різні формати завдань: вибір відповіді та введення числа/тексту;
- пояснення після помилки й повторна спроба без штрафів;
- прогрес, серія правильних відповідей і зірочки у `localStorage`;
- зміст організовано за класом, предметом і темою;
- збережено посилання на попередні окремі вправи.

Це авторська добірка тренувальних завдань, а не заява про офіційне узгодження з державною освітньою програмою. Контент можна розширювати в об'єкті `exerciseBank` у `app.js`.

## Запуск

Проєкт не потребує збірки або платних сервісів: відкрийте `index.html` у браузері або опублікуйте репозиторій як статичний сайт.

Перевірено вручну аналізом HTML/CSS/JavaScript. У репозиторії немає `package.json`, тому npm lint, automated test і production build наразі не визначені.

## Подальші кроки

Додати повноцінні вправи на перетягування з tap-альтернативою, більше текстів для читання, аудіопідтримку, автоматизовані browser-тести та CI-перевірки.
